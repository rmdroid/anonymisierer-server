## 2. Kostenfreie Nutzung (Einzelplatz)

Die Nutzung ist kostenfrei, wenn der Server auf demselben Gerät läuft, auf dem
auch die zugreifende Anwendung verwendet wird. Das gilt für private wie für
berufliche Nutzung durch eine einzelne Person.

In dieser Betriebsart ist der Server ausschließlich über die Loopback-Adresse
erreichbar (`127.0.0.1`).

## 3. Lizenzpflichtige Nutzung (Mehrbenutzer)

Eine kostenpflichtige Lizenz ist erforderlich, sobald

- der Server über ein Netzwerk von mehr als einem Gerät genutzt wird,
- der KI-Anonymisierer Windows-Agent in der Mehrbenutzerfassung eingesetzt wird,
- oder der Server für mehrere natürliche Personen bereitgestellt wird.

Die Lizenz wird als signierter Schlüssel ausgeliefert und gilt für die darin
genannte Zahl an Arbeitsplätzen und den darin genannten Zeitraum.

öffentlichen Quelle geladen. Dabei werden keine Nutzerdaten übertragen.

Server im Unternehmensnetz bleibt der Betreiber für die Einhaltung der
